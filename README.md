# NAMI Releases

NAMI 是面向 VS Code-like 工作台的市场信息扩展。

本仓库仅用于发布经过打包的安装文件，不包含产品源代码。

## 下载

- [下载最新版 NAMI（VSIX）](https://github.com/kramist/NAMI-releases/releases/latest/download/nami.vsix)
- [查看全部版本](https://github.com/kramist/NAMI-releases/releases)

## 安装

1. 下载 `nami.vsix`。
2. 在 VS Code 中打开“扩展”视图。
3. 从扩展视图右上角菜单选择“从 VSIX 安装…”。
4. 选择下载的文件并按提示重新加载窗口。

当前版本要求 VS Code `1.109.0` 或更高版本。其他 VS Code-like 工作台的兼容性以各产品实际支持情况为准。

## 完整性校验

每个版本的 Release 说明会公布安装包大小和 SHA-256。请只从本仓库的 Releases 页面下载安装包。

## 许可

安装包适用的许可和第三方声明以该安装包内附带的文件为准。
