## NAMI 是什么

NAMI 是一款原生驻留在 VS Code-like 工作台中的 AI 市场界面，面向长期工作在 Editor、Terminal 和 AI Workspace 中的用户。

它不是把股票聊天框塞进编辑器，也不是把传统行情软件缩小后搬进侧边栏。NAMI 将行情、图表、研究、Agent 和注意力管理组织成一条完整路径：

> **Ambient → Peek → Explore → Why**

市场平时安静存在；需要时快速展开；遇到异动时，继续追问原因与证据。

## 为什么使用 NAMI

| 你遇到的问题 | NAMI 的方式 |
| --- | --- |
| 工作时反复切换行情软件 | 指数、板块和自选驻留在状态栏，按 `Alt+M` 随时速览 |
| 看到异动却不知道发生了什么 | 选择分时或 K 线位置，直接使用 `/why` 追问原因与证据 |
| 查询行情、资讯、财务和选股要打开多个页面 | `/news`、`/data`、`/screen` 将结果带回同一个 Research Console |
| 不可能一直盯着市场 | 用一句“帮我盯一下光模块”创建自然语言盯盘 |
| 用户表达不总是标准证券名称 | 代码、简称、错拼和市场黑话交给 Agent 与统一证券解析处理 |

## 核心体验

### Ambient：市场在，但不打断

在状态栏放置你关心的指数、板块或自选股。展示内容由你决定，并可调整刷新周期和界面字体，不需要接受系统预设的关注列表。

### Peek：三秒看清市场

按 `Alt+M` 打开市场速览，集中查看指数、关注板块、账户自选、Sparkline、最新价格、涨跌幅和 AI 市场摘要。

### Explore：想深入时再展开

搜索并打开股票、指数或板块，在同一页面查看：

- 今日分时
- 5、15、30、60 分钟 K 线
- 日 K、周 K、月 K
- VOL、MACD、KDJ、RSI 指标副图
- 与指数、板块或其他标的的归一化相对走势
- 上一个、下一个标的快速切换

### Why：对着图表问为什么

在分时或 K 线图上选择一个位置，再输入 `/why`。NAMI 会将该时间点、价格变化、相对强度和研究信息放进同一个上下文，返回带置信度、证据卡片和后续入口的解释。

它不会假装给出唯一答案，而是帮助你更快找到与这次变化相关的证据。

## Research Console：让高密度信息有自己的工作区

Research Console 承载资讯、数据、选股结果以及 Agent 的结构化输出。它支持独立调整高度，也可以展开为更大的研究区域，让图表与研究信息在同一个界面中协同，而不是互相争抢空间。

## 一套命令，覆盖完整市场工作流

自然语言负责自由表达，斜杠命令负责快速、明确、可复用地进入专业工作流。输入 `/` 即可打开命令菜单，并使用键盘选择。

| 工作流 | 命令 | 能做什么 |
| --- | --- | --- |
| 看市场 | `/market` | 总结市场、自选与当前值得关注的变化 |
| 打开标的 | `/open` | 打开股票、指数、行业或概念板块 |
| 解释异动 | `/why` | 解释选定分时或 K 线位置的变化 |
| 研究资讯 | `/news` | 查询新闻、公告、研报、政策和事件 |
| 金融数据 | `/data` | 查询行情、资金、估值和财务数据 |
| 智能选股 | `/screen` | 使用自然语言条件筛选股票 |
| 相对走势 | `/compare` | 对比当前标的与另一标的 |
| 账户自选 | `/watch` | 查询、添加或删除账户自选 |
| 自然语言盯盘 | `/alert` | 创建、查看或删除后台关注任务 |

辅助命令：`/clear` 清空当前对话，`/help` 查看命令和键盘帮助。

```text
/open 奥比中光
/why
/news 这家公司最近有哪些公告和研报
/data 贵州茅台近五年 ROE 和毛利率
/screen 光模块板块中利润增长且估值较低的股票
/compare 创业板指
/watch 美的加入自选
/alert 帮我盯一下光模块
```

知道要去哪，就用命令直达；不知道应该用哪条命令，直接说出你的问题。

## 自然语言盯盘：把关注交出去

传统提醒要求你先确定证券代码、价格阈值和触发条件，但真实需求经常只有一句：

> 帮我盯一下光模块。

NAMI 会理解你关注的主题和市场范围，持续观察相对强度、板块广度、量能和重要事件。没有值得注意的变化时保持安静；需要提醒时，告诉你发生了什么、为什么值得关注，以及接下来可以看哪里。

## 安装

### 从 Release 安装

1. 下载最新的 [`nami.vsix`](https://github.com/kramist/NAMI-releases/releases/latest/download/nami.vsix)。
2. 在 VS Code 中打开扩展视图。
3. 点击扩展视图右上角的 `…`，选择 **Install from VSIX...**。
4. 选择下载的 `nami.vsix`。
5. 安装完成后按 `Alt+M`，或运行 `NAMI: Open Market`。

也可以在下载目录执行：

```text
code --install-extension nami.vsix
```

要求：VS Code `1.109.0` 或更高版本。当前市场范围以 A 股、指数和板块为主。其他 VS Code-like 工作台的兼容性以各产品实际支持情况为准。

## 连接研究与数据服务

需要资讯、结构化金融数据、自然语言选股和账户自选能力时：

1. 打开 NAMI 顶部的研究与数据服务配置入口。
2. 按配置界面的说明获取服务访问凭据。
3. 粘贴凭据并完成连接测试。

服务访问凭据保存在 VS Code SecretStorage 中，不写入项目、设置文件或日志。

## 连接 AI

行情、搜索和图表不要求连接模型。需要 AI 市场摘要、自由问答和 `/why` 时：

1. 运行 `NAMI: Configure AI`，或点击界面中的 **LLM**。
2. 选择兼容的模型服务。
3. 填写模型、服务地址和 API Key，并完成连接测试。

NAMI 不绑定唯一模型服务。API Key 同样保存在 VS Code SecretStorage 中。

## 隐私与产品边界

- Agent 请求只携带当前问题和为该问题准备的市场上下文，不发送编辑器源代码。
- AI 与外部服务凭据不会写入工作区、VS Code 设置、Webview 状态或日志。
- 已保存的 AI 与外部服务连接可以随时从 NAMI 配置入口中清除。
- NAMI 组织市场信息与研究证据，不执行交易，也不承诺预测结果。
